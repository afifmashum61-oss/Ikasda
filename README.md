# IKASDA - Portal Resmi Alumni & Santri Pondok Pesantren Darussalam Ngesong Jombang

Selamat datang di portal resmi **IKASDA (Ikatan Alumni & Santri Pondok Pesantren Darussalam Ngesong Sengon Jombang)**. Portal web interaktif ini memadukan kehangatan silaturahmi alumni dengan sistem direktori modern, timeline kepengurusan dari masa ke masa, dokumentasi kegiatan, serta integrasi manajemen data.

---

## 🌟 Fitur Utama

- **Hero Slider Imersif (3 Slide Interaktif)**:
  1. *Beranda Utama*: Lanskap Masjid Al-Huda & Profil Pesantren.
  2. *Majelis Masyayikh & Pengasuh*: Jajaran Pengasuh Pesantren dalam panorama lembut.
  3. *Munas & Silaturrahim Akbar*: Dokumentasi resmi Munas IKASDA Ngesong lintas generasi.
- **Direktori & Pencarian Alumni**: Pencarian nama, angkatan, Korda (Koordinator Daerah), dan profesi.
- **Timeline Kepengurusan dari Masa ke Masa**: Arsip struktural kepengurusan IKASDA lintas periode.
- **Katalog Agenda & Berita**: Berita pesantren, info reuni, bakti sosial, dan agenda dakwah.
- **Pendaftaran / Update KTA Alumni**: Formulir interaktif untuk registrasi anggota IKASDA.
- **Desain Modern & Responsif**: Berbasis tipografi elegan, micro-interaction mulus, dan palet warna islami bernuansa zamrud modern (*Emerald & Slate*).

## 🚀 Cara Menjalankan Secara Lokal

1. Pastikan [Node.js](https://nodejs.org/) terpasang di perangkat Anda.
2. Clone repository:
   ```bash
   git clone https://github.com/afifmashum61-oss/Ikasda.git
   cd Ikasda
   ```
3. Jalankan server lokal:
   ```bash
   node server.js
   ```
4. Buka browser pada alamat:
   ```
   http://localhost:3000/
   ```
